### Legenda de status

- ✅ **verificado**: a página foi aberta e lida.
- ⚠️ **parcial / não verificado**: a página não pôde ser aberta. As informações vêm de busca na web ou estão faltando.
- ❌ **fora do ar**: o link não funciona mais.

## Como adicionar um item

Copie o modelo abaixo para o arquivo da categoria certa e atualize o índice acima.

```markdown
## Nome do item

- **Link:** https://...
- **Tipo:** repositório | portfólio | post | ferramenta
- **Tags:** tag1, tag2
- **Status:** ✅ | ⚠️ | ❌
- **Adicionado em:** AAAA-MM-DD

**O que é:** uma ou duas frases.

**Quando usar:** em que situação isso pode ser útil.

**Notas:** detalhes, requisitos, custos, alternativas.
```
